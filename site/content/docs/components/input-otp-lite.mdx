## About

Input OTP (Lite) is a hand-written alternative to shadcn/ui's [Input OTP](https://ui.shadcn.com/docs/components/base/input-otp), which is built on the React library [input-otp](https://github.com/guilhermerodz/input-otp). It keeps upstream's look in every style: one native text input lies over the slot boxes, its characters spaced to one per box, so typing, pasting, one-time-code autofill and form validation come from the browser.

## Usage

```tsx
import { InputOTPLite } from "@/components/ui/input-otp-lite"
```

```tsx
<InputOTPLite maxLength={6} name="code" />
```

Unlike upstream, it is one component: `maxLength` sets the number of slots, and the input takes every attribute of a text input (`name`, `pattern`, `required`, `value`, `disabled`, `aria-*`).

## Pattern

Use `pattern` and `inputmode` for what the code accepts. Characters line up with tabular digits; set a monospace font for letters.
