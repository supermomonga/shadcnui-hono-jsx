The CLI is released to npm from the repository. Release notes are on [GitHub Releases](https://github.com/supermomonga/shadcnui-hono-jsx/releases), and every release is on [npm](https://www.npmjs.com/package/shadcnui-hono-jsx).

Upstream changes arrive through weekly pull requests that sync the shadcn/ui registry and regenerate the components; they ship with the next release.
